# Sign-up Form

A basic sign-up form built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## Technologies Used

* HTML5
* CSS3
* VS Code
* Git

## About the Project

The goal of this project was to practice building and styling forms, as well as implementing basic client-side form validation using HTML and CSS, without JavaScript.

## What I Practiced

* Structuring forms with semantic HTML
* Styling form elements with CSS
* Using CSS pseudo-classes such as `:focus` and `:invalid`
* Implementing client-side validation without JavaScript
* Using HTML validation attributes
* Working with Git and GitHub
